# על אותו גל

משחק קלפים זוגי — 250 קלפים של צחוק, שיחה וקרבה.

**לשחק:** <https://b0504171366-maker.github.io/al-oto-gal-music/>

## התקנה כאפליקציה

- **אנדרואיד / כרום:** תפריט ⋮ ← ״התקנת אפליקציה״ או ״הוספה למסך הבית״
- **אייפון / אייפד:** כפתור השיתוף ← ״הוספה למסך הבית״

אחרי ההתקנה המשחק נפתח במסך מלא, בלי סרגלי דפדפן, עם אייקון משלו,
ועובד גם בלי חיבור לרשת — חוץ מהמוזיקה.

## מה יש כאן

| קובץ | תפקיד |
|---|---|
| `index.html` | המשחק כולו — HTML, CSS ו-JS בקובץ אחד |
| `manifest.webmanifest` | הגדרות ההתקנה כאפליקציה |
| `sw.js` | Service Worker — עבודה בלי רשת |
| `icon-*.png` | אייקוני האפליקציה |
| `ambient-95min.mp3` | מוזיקת רקע — 95 דקות ברצף |

## על המוזיקה

רצועה אחת של 95 דקות, ב-96kbps (65MB). ערב שלם בלי מעבר בין שירים
ובלי שהמנגינה חוזרת על עצמה.

הקובץ **אינו נטען עד שלוחצים על כפתור המוזיקה**, והדפדפן מוריד
רק את החלק שמתנגן בפועל. ערב של 40 דקות מוריד כ-28MB, לא 65.

המוזיקה אינה נשמרת במטמון בכוונה — היא גדולה מדי לאחסון אוטומטי.
